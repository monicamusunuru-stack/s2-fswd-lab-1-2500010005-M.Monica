# Student Portal

A web-based Student Portal application developed using the MERN stack (MongoDB, Express.js, React.js, and Node.js).

## About the Project

The Student Portal is designed to manage student information through a simple and user-friendly web interface. It connects the frontend with a backend API and MongoDB database to store and retrieve student records.

## Technologies Used

- **Frontend:** React.js
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Programming Language:** JavaScript
- **Version Control:** Git & GitHub

## Installation and Setup

1. Clone the repository.
2. Install backend dependencies using `npm install`.
3. Install frontend dependencies using `npm install`.
4. Configure the environment variables.
5. Start the backend and frontend servers.
